# Dotfiles

Personal shell and terminal configurations, kept in this repo so they can be
synchronized across devices via Git.

## Layout

- `zsh/zshrc` — Zsh configuration, deployed as `~/.zshrc`. Secrets are removed;
  machine-specific values are loaded from `~/.zshrc.local` (never tracked).
  Homebrew-dependent bits degrade gracefully when brew/opt paths are absent
  (e.g. on Linux).
- `zsh/p10k.zsh` — Powerlevel10k prompt config, deployed as `~/.p10k.zsh`.
  Generated by `p10k configure`; portable across devices.
- `zsh/zshrc.local.example` — template for `~/.zshrc.local` (secrets, per-device
  overrides). Copy it to `~/.zshrc.local` on each device and fill in real values.
- `tmux/tmux.conf` — Tmux configuration, deployed as `~/.tmux.conf`. Plugin paths
  use `$HOME` instead of a hard-coded username. TPM plugins are installed
  per-device and are not tracked.
- `tmux/tmux.conf.local.example` — template for `~/.tmux.conf.local` (per-device
  tmux overrides, e.g. Linux clipboard commands). Sourced last by `tmux.conf`;
  never tracked.
- `install.sh` — idempotent installer: backs up any existing files, then symlinks
  the managed configs into `$HOME`, and creates `~/.zshrc.local` /
  `~/.tmux.conf.local` from the examples if they do not exist yet.

## Install on a new device

```bash
git clone <repo> && cd <repo>
./dotfiles/install.sh
```

Then edit `~/.zshrc.local` (credentials/overrides) and `~/.tmux.conf.local`
(device-specific tmux options) for that device. Install Tmux plugins afterwards
if needed (`prefix + I` via TPM), and reload Tmux config with `prefix + r`.
Re-generate `~/.fzf.zsh` with `fzf --zsh` if fzf history completion is wanted
(the rc sources it only when present).

## Sync workflow

- Configs live here and are symlinked, so edits made via `~/.zshrc`,
  `~/.p10k.zsh` or `~/.tmux.conf` are already edits to the repo.
- Never commit `~/.zshrc.local`, `~/.tmux.conf.local`, or any real credentials.
- The example files and this repo must stay secret-free; check with
  `grep -n "accessKey\|JUMP_NEON_PASSWORD" dotfiles/` before pushing.

## Platform notes

- The Zsh config assumes a macOS machine (Homebrew, pyenv, goenv, jenv, nvm,
  pnpm paths). On Linux, adjust those paths in your copy or via
  `~/.zshrc.local`; brew-only `source` lines are already guarded so they do not
  hard-fail.
- The Tmux config uses macOS-specific clipboard commands (`pbcopy`,
  `reattach-to-user-namespace`). On Linux, switch those to `xclip`/`xsel` in
  `~/.tmux.conf.local` and drop the `reattach-to-user-namespace` wrapper in
  `default-command`.
- Oh My Zsh, Powerlevel10k, fzf, and the tmux TPM plugins are installed
  per-device (e.g. via the oh-my-zsh installer, `p10k configure`, and
  `prefix + I`); only their configuration is tracked here.
