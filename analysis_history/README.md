# 个股分析历史

此目录保存可追溯的技术分析记录，目录和文件名按“股票代码 / 分析日”组织：

```text
analysis_history/
├── 002428/
│   └── 2026-08-31.json
├── 300139/
│   └── 2026-08-31.json
├── 300209/
│   └── 2026-08-31.json
├── 301717/
│   └── 2026-08-31.json
├── 600183/
│   └── 2026-08-31.json
├── 603228/
│   └── 2026-08-31.json
├── 688183/
│   └── 2026-08-31.json
└── 688362/
    └── 2026-08-31.json
```

每个 JSON 文件是一只股票在一个自然日的唯一记录。记录包含日线与周线指标、量价/结构证据、
条件观察位（止损、目标、风险收益和失效条件）、数据来源与抓取时间，以及与上一份同股票记录
的复盘结果。远端缓存命中仍保留原始 provider 来源，并在 `provenance.cache_hit` 标明。

生成或更新记录：

```bash
.venv/bin/python -m research.technical_analysis.run
```

默认分析生益电子（`688183`）和生益科技（`600183`）；甬矽电子（`688362`）、云南锗业
（`002428`）、晓程科技（`300139`）、行云科技（`300209`）、景旺电子（`603228`）和超纯应材
（`301717`）可通过
重复 `--symbol` 加入同一批次。`--source fixture` 只用于离线测试，不能作为市场结论。
记录是研究输出，不构成投资建议；当前技术分析没有宣称经过这些标的的含成本回测或样本外验证。
