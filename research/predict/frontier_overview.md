# 股票走势预测前沿研究综述（2024–2026）

> 状态：调研初稿（2026-10-15），基于公开论文与行业资料，面向 `research/predict/` 研究方向的前沿定位与选题参考。
> 性质：研究综述，非投资建议。论文结论常依赖特定数据集与回测设置，需自行复现验证。

## 1. 问题定义与预测目标

股票/证券走势预测的核心问题是：给定截至时刻 T 的可得信息（价格、成交量、基本面、新闻、另类数据等），预测未来走势。按预测目标可分为：

- **方向预测（Movement Prediction）**：未来 N 日/时段涨跌分类（如 1/3/7/10 日），是最常见设定。
  对应评测指标：方向准确率（Direction Accuracy，DA），即预测方向与真实方向一致的占比。
- **价格/收益率回归**：预测未来价格或连续收益率，常用 MSE 或分位数损失。
  对应评测指标：信息系数（IC，Information Coefficient），即预测值与真实收益率的相关性。
- **波动率预测**：预测未来波动区间，常用于风险与仓位管理。
  对应评测指标：预测误差（如 RMSE，Root Mean Square Error）或区间覆盖率（Coverage）。
- **排序/相对强弱（Ranking）**：预测多只股票未来收益的相对排序，用于选股组合构建。
  对应评测指标：秩信息系数（Rank IC，Rank Information Coefficient），即预测排序与真实排序的相关性。
- **事件驱动预测**：结合公告、新闻、突发事件预测短期异动。
  对应评测指标：决策端指标，如事件窗口超额收益、分层组合多空收益。

各目标的评测口径与组合使用详见第 2 节。

多数前沿研究已从"预测价格"转向"预测运动方向 + 不确定性量化 + 交易可执行性"，因为价格回归的绝对误差难以直接转化为交易收益。

#### 为什么这样说？（对这句话的解释）

这句话的核心是：**预测目标必须与交易决策的目标对齐，否则再小的预测误差也换不来收益**。可以拆成三层理解：

1. **价格回归的误差度量与交易盈亏脱节。** "预测价格"通常用 MSE/MAE 衡量，但模型只需要把误差从 1.0 降到 0.5，并不会自动变成钱。交易盈亏取决于"买/卖/持有"这个离散动作是否做对：即使预测价格只差 0.2 元，只要方向（涨/跌）判断反了，照样亏损；反之方向对了，误差大一些也可能盈利。也就是说，连续误差最小化与离散动作收益之间没有直接映射。
2. **方向预测天然对应交易决策。** 交易本质是离散动作（买入、卖出、持有），把预测目标改成"未来 N 日涨/跌"这类分类问题，损失函数与最终决策直接对齐，信号也更易转成可执行的买卖规则。
3. **不确定性量化解决"预测对了但不敢下单"的问题。** 市场信噪比极低，单点预测（如"明天涨 2%"）无法告诉人有多可信。前沿方法转而输出概率或置信区间（如分位数回归、蒙特卡洛 Dropout、Conformal 预测），让"大概率涨"与"勉强看涨"区别对待，用于仓位大小、止损和风控——这是把预测变成决策的必要环节。
4. **交易可执行性决定预测是否有用。** 一个预测即使方向和概率都对，如果回测忽略了 T+1、涨跌停、滑点、手续费、流动性和停牌，它的"纸上收益"就无法落地。因此前沿研究把评价闭环从"预测准确率"扩展到"信号 → 可执行策略 → 扣成本后的真实收益"，预测只有通过这个闭环才被认为有研究价值。

#### 补充理解：为什么"单点预测"不可信？

"市场信噪比极低"可以这样理解：价格每天的变动里，**真正可预测、有规律的部分（信号）占比很小，其余大部分是随机噪声**。A 股个股日涨跌幅多数集中在 ±2% 以内，其中很大一部分来自情绪、流动性摩擦和随机买卖，而不是可被模型捕捉的确定性信息。信噪比低，意味着模型从同样的输入里"看到"的规律很弱，预测天然充满不确定性。

"单点预测（如明天涨 2%）无法告诉人有多可信"，问题在于它只给了一个**均值/点估计，没有给分布信息**：

- 同样输出"明天涨 2%"，可能是"信号很强、几乎确定"的 2%，也可能是"纯噪声碰巧算出"的 2%——单看这个数字无法区分。
- 没有可信度，就无法回答决策层的问题：该下多少仓位？要不要设止损？能不能加杠杆？预测越不可信，仓位越应该小。
- 因此前沿方法输出**概率、置信区间或整个分布**（分位数回归、蒙特卡洛 Dropout、Conformal 预测等），让"大概率涨 2%"和"勉强看涨 2%"成为两个可区别对待的信号。

可以类比天气预报："明天 28°C"是单点预测，而"70% 概率 26~30°C"才告诉你该带伞还是穿短袖。股票预测同理：**点估计只回答"是什么"，概率/区间才回答"有多确定"，后者才支撑仓位和风控决策。**

一句话总结：**预测价格是在优化"数字准不准"，而预测方向、量化不确定性和保证可执行，是在优化"能不能赚钱"**——后者才是交易研究真正关心的目标。

## 2. 评测指标：从"预测对不对"到"赚不赚钱"

> 四个指标逐层递进，分别对应第 1 节的预测目标：IC 与 Rank IC 看排序/回归能力，方向准确率看方向判断，决策端指标看能否变成收益。建议管道搭建时四个都算、输出一张统一报告；任何模型上线前先过这一关（评估红线见第 5 节）。

### 2.1 IC（Information Coefficient，信息系数）

预测值与真实收益率之间的相关性（一般用 Pearson，或对单票用时间序列上的相关性）：

IC = corr(预测收益率, 实际收益率)

- **截面 IC（选股/因子场景最常用）**：某一天对全部股票算"预测收益 vs 实际收益"的相关性，再对每天取平均。
- **时序 IC（单票预测场景）**：同一只股票，滚动 N 天的预测 vs 实际。
- 经验阈值：|IC| > 0.02 可做信号，> 0.05 不错，> 0.1 很强；ICIR = mean(IC)/std(IC) 看稳定性，> 0.5 才靠谱。
- 为什么用相关性而不是误差：MSE 惩罚绝对偏差（预测 8%、实际 10% 就被扣分），但预测真正在意的是相对强弱；相关性忽略整体偏移，只看"预测升的时候实际是否也升"——数字差点没关系，顺序对就行。

### 2.2 Rank IC（秩信息系数）

用排名而不是数值算的 IC，即 Spearman 相关：corr(rank(预测), rank(实际))。

- 好处：不敏感于极端值和非线性——预测 0.1 还是 0.05 的实际含义不重要，重要的是谁排在前面。
- 选股场景里 Rank IC 比 IC 更常用，因为最终决策只看相对顺序（买排名靠前的）。
- 局限：它只证明"排序一致"，不证明预测数值可信，也不能直接证明赚钱。

### 2.3 方向准确率（Direction Accuracy，DA）

预测方向（涨/跌）与真实方向一致的占比：

DA = 预测方向正确的天数 / 总天数

- 直觉、好懂，随机基线是 50%。
- 大坑：牛市里无脑看多也能拿 70%+，单独看会被市场环境欺骗；必须按市场状态分组看（单边市 vs 震荡市），或配合其他指标。

### 2.4 决策端指标（把预测变成钱）

前三者只回答"预测准不准"，这里回答"按预测操作赚不赚钱"：

- **分层组合（分位组合）**：每天按预测值把股票分 10 组，做多预测最高的组、做空最低的组，看多空价差收益——最能直接反映预测的排序价值。
- **多头组合超额**：只买预测 Top 20%，对比基准（如沪深 300）的超额收益。
- **风险调整**：Sharpe、最大回撤、年化收益（必须扣掉换手成本，否则高频信号看起来很赚、实际不赚）。
- **可靠性**：不只问预测，还问"预测 → 动作 → 置信度"整条链是否可靠，防止模型靠 HOLD/低置信度躲掉错误预测。

### 2.5 为什么四个要一起用

每个指标单独都能被"骗"：

- IC 高但极端值主导 → 用 Rank IC 校正。
- 方向准确率高但可能是牛市假象 → 按市场状态分组看。
- 预测准但不赚钱 → 决策端指标兜底。
- 赚钱但靠运气/未来函数 → 防泄漏协议兜底（第 5 节）。

数字例子（5 只股票，预测 vs 实际）：

| 股票 | 预测 | 实际 |
|---|---|---|
| A | 8% | 10% |
| B | 5% | 4% |
| C | 2% | 1% |
| D | -1% | -3% |
| E | -6% | -9% |

- IC（Pearson）≈ 0.97，方向准确率 = 5/5 = 100%，Rank IC ≈ 1.0——排序几乎完美。
- 决策端：做多 A、做空 E，收益 = 10% - (-9%) = 19%——这才是实际能拿到的。

一句话记忆：**IC/Rank IC 看"排序能力"，方向准确率看"方向判断"，决策端指标看"能不能变成钱"。**

| 行情数据 | OHLCV、复权因子、盘口/L2 订单流 | AkShare、easy-tdx、Wind |

## 4. 方法谱系与前沿进展

> 本节按方法族组织，但只评价各方法在**股票预测任务**（方向/收益率回归、横截面排序、不确定性量化、可执行信号）上的价值；通用时序基准分数不作为选型依据。任何方法在 A 股落地前都要过同一套标准：任务是否与交易决策对齐、是否处理非平稳性、是否存在前视泄漏、回测是否含 T+1/涨跌停/成本（与第 5、6 节一致）。

### 4.1 传统统计与机器学习基线

- ARIMA/GARCH 类：仅适合低信噪比下的简单基准，在个股次日方向任务上几乎不构成竞争力。
- 树模型（XGBoost/LightGBM）：特征工程强、可解释性好，仍是**中低频单股"次日方向"预测最实用的基线**，也是本项目第 6 节基线路径的起点。
- 线性因子模型：Barra、Fama-French 属组合层框架，解决多股横截面排序/配置，不直接预测个股方向；作为选股基准对照，而非单股预测方法。

共性定位：这类方法的价值是"可复现的强基线 + 可解释特征"，前沿能力有限，但任何新方法都应与它们对照，而不是只与深度学习模型互比。

### 4.2 深度学习（非 Transformer）

- **CNN**：1D-CNN 对价格/分钟序列卷积，配合 SHAP/Grad-CAM 解释特征（如 2025 FinTech 论文对 S&P 500 的实验），常用于 K 线形态与短窗口模式识别。
- **LSTM/GRU**：经典的日线/分钟收益率序列建模基线，对长程依赖能力有限，单市场泛化差。
- **TCN**：因果卷积 + 空洞卷积，训练稳定、梯度可控，常作为 Transformer 的轻量替代，适合长序列方向特征。

共性局限：这类模型多为"单标的单任务"设计，换市场/换股票往往需要重训，且对非平稳漂移敏感；在股票预测中应作为可复现基线而非终点。

### 4.3 预训练基础模型（股票预测落地视角）

通用时序基础模型本身不针对金融，**用于股票预测的常见路径是：零样本打底 → 金融数据微调 →（可选）横截面排序/事件标注**；单独报告通用基准分数对选股没有意义。

- 通用时序基础模型代表：Chronos（数值 token 化）、Moirai（掩码编码器）、TimesFM / Lag-Llama / Moment / TiRex 等，零样本能力不错，但金融数据非平稳性强，通常需在金融数据上继续微调。
- 通用 Transformer 主干（PatchTST / iTransformer / Informer 等）已逐渐让位于基础模型路线，仅在中小数据集上仍作主干基线。
- **FinCast**（CIKM 2025）：目前少有的**专为金融时序设计**的基础模型，用 MoE 按 token 激活 top-k 专家，在跨数据集泛化上优于通用模型，是与股票预测最直接相关的前沿方向。

对股票预测的启示：优先验证"零样本 + 少量微调"在目标市场（尤其 A 股）方向/排序任务上的表现与微调成本，并同时报告样本外与扣成本后的收益，而不只是通用 MSE。

### 4.4 图神经网络（关系建模）

近年趋势是把"股票之间的联动"显式建模为图，服务于单股预测时的关系特征与横截面排序：

- **关系图构造**：行业、供应链、同涨同跌（相关性）、共同新闻。
- **代表模型**：
  - MDGNN（蚂蚁集团，2024）：多关系动态图 + Transformer 编码时序演化，在多市场 SOTA。
  - DiffSTOCK（2024）：扩散模型 + 图关系，做概率式市场预测。
  - ViT-LOB：用 Vision Transformer 处理订单簿数据预测走势。
- **价值**：把"联动性"显式建模，比独立看待单只股票更接近市场真实结构。
- **局限**：关系图的边必须稳定且无前视（如只用截至 T 的行业/相关性），否则易引入泄漏。

### 4.5 大语言模型（LLM）与金融智能体

这是 2024–2026 最热的方向之一，定位是把文本信号（新闻/公告/研报）转化为短期走势预测与事件驱动信号：

- **FinGPT / BloombergGPT / FinBERT**：金融语料预训练或微调的 LLM，用于情感分析、新闻解读。
- **FinGPT（2025 改进版）**：把新闻的"传播广度 + 上下文 + 显式指令"注入 prompt，再指令微调，短周期走势预测准确率提升约 8%。
- **FinMem**（IEEE TBD，2025）：分层记忆 + 角色设计，让 LLM 自主交易，相比传统算法代理在累计收益与 Sharpe 上更优。
- **FinAgent / 多智能体系统**：LLM 充当"研究、风控、执行"各角色协同决策。
- **AlphaAgent / AlphaLogics**：用 LLM 自动挖掘因子表达式，并带"反 Alpha 衰减"的约束探索。
- **风险提示**：LLM 预测常受 lookahead bias（预训练数据含未来信息）污染，需专门测试。

### 4.6 多模态方法

- **K 线图图像**：把 30 日窗口 K 线转成图像，用 CNN/ViT 学习图表形态（如 Sezer & Ozbayoglu 的 CNN 方案），用于日线方向分类。
- **混合模型**（IEEE Access 2025）：ViT 处理 K 线图 + Temporal Fusion Transformer 处理时序特征，多模态融合预测 1/3/7/10 日方向。
- **订单簿 LOB**：ViT-LOB 等处理逐笔/盘口数据，目标是分钟级方向预测（非日线），数据门槛高，A 股 L2 可得性需单独评估。

### 4.7 强化学习（交易执行与组合）

- 定位澄清：RL 直接学习"买卖持有"属于**执行/组合层**，不是价格预测本身；端到端方案因可解释性与样本效率差，一般只作对照。
- 更务实的路线：预测层（监督学习）+ 执行层（RL 优化交易成本与仓位）分层，预测质量仍是核心。

### 4.8 扩散/生成模型

- DiffSTOCK（2024）：DDPM 生成未来价格分布——目的不是点预测，而是输出"方向概率 + 区间"，正对第 1 节"不确定性量化"目标。
- 生成式方法主要用于：不确定性量化、场景合成、模拟回测。
- 落地注意：需验证生成分布与真实分布的偏差，避免把模拟样本当作真实行情。

## 5. 核心挑战与陷阱（重要）

前沿研究反复强调以下问题，也是本项目落地时的红线：

1. **前视偏差（Look-ahead / Data Leakage）**：特征用了未来信息（如未来复权因子、未来财务数据、LLM 预训练语料）。最新研究（如 "When Alpha Disappears" 2026）专门做决策时点泄漏诊断基准。
2. **回测不真实**：忽略 T+1、涨跌停、交易成本、滑点、流动性、停牌，导致回测收益不可执行。
3. **非平稳性与过拟合**：金融数据随时间漂移，超参数/特征在历史窗口调优后在样本外失效，存在 Alpha 衰减。
4. **基准问题**：应与 Buy & Hold、随机游走、简单因子模型对比，而不只是"比另一个深度学习模型好"。
5. **复现性问题**：论文常缺少数据版本、预处理细节与 seed，11 个模型复跑有 7%~79% 结果不一致（2026 研究）。
6. **数据质量**：填充缺失值、复权口径、停牌处理不当会扭曲结果。

## 6. 结合本项目的落地建议

结合 `AGENTS.md` 与仓库现状，建议 `research/predict/` 优先做以下可验证的实验路径：

1. **基线先行**：用远程 AkShare 数据（`AkShareMarketProvider` 路径）构建"次日方向"分类基线（XGBoost/LightGBM），严格 T+1、涨跌停、成本与流动性约束，用 AKQuant 回测。
2. **特征方向**：先做"量价 + 技术指标 + 基本面 + 新闻情绪"的简单融合，再评估是否引入关系图（行业/联动）。
3. **模型方向**：从时序基础模型（Chronos/Moirai 类零样本）与 LLM 情感融合（FinGPT 思路）两个支线并行，但都以"回测可执行"为准绳。
4. **评估红线**：每次实验报告必须记录数据源、观测日期、复权口径、回测参数、是否存在泄漏检查；禁止把日志输出当指标。
5. **落地约束**：不引入未验证的本地 Parquet/DuckDB 快照；保持 provider 与策略分离；结果仅作研究输出。
