# 论文笔记：KiT — 金融时序预测的扩散 Transformer 基础模型

> 来源：arXiv:2609.34507v1 [cs.LG]，2026-09-28 提交，2026-10-15 基于摘要页与 HTML 全文整理。
> 性质：论文研读笔记；文中的数字与结论均为作者报告值，未经本仓库独立复现验证。

## 1. 基本信息

- **标题**：KiT: A Foundation Model for Financial Time-Series Forecasting using Diffusion Transformers（K 线扩散 Transformer 金融时序基础模型）
- **作者**：Boyu Zhang（UCLA）、Haorui Li（东南大学），共同一作
- **领域**：cs.LG / cs.CV；代码：https://github.com/Luciferbobo/KiT（论文称"将提供"，尚未验证）
- **一句话定位**：把"预测未来 K 线"重定义为**条件路径生成**（flow matching + Diffusion Transformer），一次推理输出一整组未来 OHLCV 轨迹，而不是单个点预测。

## 2. 要解决什么问题

- K 线（OHLCV）预测是量化投资的基础，但有两个硬伤：
  1. **信噪比极低**：可预测信号远弱于噪声；
  2. **跨市场/工具异质性极大**：绝对价格、波动区间、成交量单位各不相同，难以用一个模型统一建模。
- 现有方案的缺陷：
  - 主流深度学习用**自回归**公式，推理时误差累积（一步错步步错）；
  - 通用时序基础模型（Chronos、TimesFM 等）不是为 K 线结构设计的，下游表现不理想。

#### 怎么理解"自回归误差累积"？

自回归（autoregressive）预测的思路是：**先预测 T+1，再用预测出来的 T+1 作为输入去预测 T+2，再用预测的 T+2 去预测 T+3……像多米诺骨牌一样一步步滚下去**。LSTM、Transformer 解码器式模型做多步预测大多是这种套路。

问题出在"预测值被当成输入喂回去"这个循环上：

1. **训练与推理不一致（核心机制）**：训练时模型用的是**真实历史值**当输入（teacher forcing），推理时却要用**自己预测出来的值**当输入。模型从没见过"自己的错误输出"，一旦第一步预测偏了，第二步就在这个偏了的输入上继续预测——偏差被放大而不是被纠正。
2. **误差会累积传播**：每一步的误差都进入下一步的输入，多步滚动后误差叠误差，越滚越大。金融序列信噪比本来就极低（前文第 2 节），单步预测已经不准，长 horizon 的滚动预测很快就退化到噪声或"均值回归"水平。
3. **类比**：就像开车时每一步导航都偏一点，你还拿"偏了的导航结果"去算下一步，越走越偏——"差之毫厘，谬以千里"。

这也是 KiT 改用 flow matching 直接**生成整段未来路径**的原因：它不滚动，而是从噪声一次性还原一条完整的未来 OHLCV 轨迹，条件只挂在历史上下文上，模型输出不会被当作下一步的输入，因此没有"误差喂回"的循环；多条路径还能给出分布和区间。

## 3. 核心方法

### 3.1 把 K 线编码成"尺度无关、可逆、几何合法"的 5 维状态

原始 OHLCV 不适合做扩散状态（绝对价格差 3 个数量级、波动区间随周期变化、量纲各异）。KiT 把每根 K 线分解为 5 维 log-ratio 状态：

| 分量 | 含义 |
|---|---|
| `r_gap` | `ln(O_t / C_{t-1})`：跳空 |
| `r_body` | `ln(C_t / O_t)`：实体 |
| `r_up`  | `ln(H_t / max(O,C))`：上影 |
| `r_dn`  | `ln(min(O,C) / L_t)`：下影 |
| `v`     | `ln((V_t+1) / (E_t+1))`：成交量相对严格因果的成交量 EMA |

三个关键性质：

- **可逆**：给定前收 `C_{t-1}`，5 个坐标可闭式链式指数恢复完整 OHLCV，信息无损；
- **尺度无关**：全是对数比率，对绝对价格水平和成交量乘性缩放不变，一个模型可跨工具/市场；
- **结构合法**：`r_up`、`r_dn` 由构造保证非负，生成时 clamp 强制约束，解码出的 K 线几何永远合法。

### 3.2 训练与推理：flow matching + 双分类器自由引导（CFG）

- **训练目标**：masked MSE（flow matching 速度场），只在目标位置算损失；上下文 token 参与注意力但不计损失；flow time 用 logit-normal 采样。
- **条件丢弃**：训练时随机三种丢弃——工具/行业 embedding 换成共享 `[UNK]`；身份信号（市场/行业/工具/时间尺度）全换 `[NULL]`；整个历史上下文清零。
- **推理**：从高斯噪声出发，Euler 求解 ODE；用**双轴 CFG**（身份权重 `w_id` + 历史权重 `w_hist`）调节预测分布。
- **输出**：采样 M 条独立 OHLCV 轨迹（论文默认 16 条并取平均），任何分布统计量（均值、分位数、区间）直接由这组轨迹计算——这天然就是"预测 + 可信区间"。

### 3.3 规模

- 三个参数量：KiT-S（31M）、KiT-M（101M）、KiT-L（284M），评估用最大版。
- 训练：AdamW、BF16、global batch 4096、EMA 0.9999、峰值 lr 1e-4（1000 步 warmup）、**128 张 NVIDIA H200**，训练到验证损失不再改善。

## 4. 数据与实验

- **数据**：3 个市场 × 7 个时间尺度（1/5/15/30 分钟、1/2 小时、1 日）：A 股 3,914 只、美股 888 只、加密货币 28 个产品；2016-08-01 ~ 2026-04-10；合并共 **4,830 个工具、约 30 亿根 K 线**（1 分钟源聚合到粗网格）；价格后复权；归一化统计量（按市场/尺度的 MAD）只在训练期拟合。
- **切分**：训练至 2023-12-31；验证 2024-01-01 ~ 2025-12-31；测试 2026-01-01 ~ 2026-04-10。
- **基线**：Kronos、Sundial、Chronos-Bolt extended、Chronos-2、TimesFM 2.5、TimesFM 3，以及历史收益 bootstrap、GARCH，和适配过的生成模型 TimeGrad、Diffusion-TS、TSFlow。
- **结果**：三个市场、七个分辨率下，平均收益 RankIC **0.057**、平均波动率 RankIC **0.66**，每个时间尺度都领先专用金融预测器与通用时序基础模型；另有理论回测章节说明其路径预测的经济相关性。

## 5. 结论与展望

- 不需要离散 tokenizer，可无缝容纳高维输入（Level-3 订单簿、alpha 因子）；
- 未来方向：更高维数据、下游任务微调、把 KiT 当基础模型做定向微调。

## 6. 对 `research/predict/` 的启示（"看上限"）

这篇是扩散 Transformer 在金融时序上的代表作，它给出的**上限信号**值得对照我们的基线方案：

1. **收益方向的可预测性上限很低**：30 亿根 K 线 + 284M 参数 + 128×H200 的顶级资源，收益平均 RankIC 也只有 0.057（约 0.05 就被认为是"有意义的 alpha"）。这印证了基线方案里"别指望高准确率，要指望弱信号 + 严格回测"的定位。
2. **波动率远比收益可预测**：波动率 RankIC 0.66 远高于收益。这直接支持形态 B——"涨跌幅点估计 + 可信区间"：区间的宽度（波动率部分）可信度高，期望收益弱但存在。
3. **生成式多路径采样是"区间预测"的上限形态**：一次推理给整条 OHLCV 分布，分位数/区间只是分布的投影；比分别训练多个分位数模型更完整，可作为形态 B 的远期升级方向。
4. **可借鉴的工程细节（与规模无关）**：log-ratio 尺度无关编码、严格因果特征（成交量 EMA 用过去信息）、归一化统计量只在训练期拟合、后复权价格——这些在个人规模的研究里同样适用。
5. **复现边界**：论文代码尚未验证；数字为作者自报；测试窗口（2026 年初）与数据口径需要独立复现才能采信。对我们而言，可参考其思路，但不应把它当"本地上限"。
