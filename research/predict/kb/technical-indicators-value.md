# 技术指标（MACD 等）要不要加

- 标签：`特征工程` `技术指标` `信息量` `对照实验`
- 收录日期：2026-10-19

## 最精炼要点

1. MACD 等经典指标是价格/成交量的确定性变换（EMA 差的线性组合），不携带新的信息；XGBoost 的树能自行学出这类组合，当特征已有 `ret_*`/均线乖离/波动/量比时，MACD 的边际信息增益接近 0。
2. 可能有边际意义的类型：位置/状态类（距 N 日高低点、布林带位置、RSI 区间映射）；缺失维度（成交额、换手率）；离散状态显式编码（金叉/死叉、背离）。
3. 实证共识：公开技术指标在日频上的单独预测力很弱；真正的增量来自截面/多源/另类数据（资金流、情绪、基本面、龙虎榜）以及无泄漏标签与正确口径。
4. 推荐做法：做对照实验（加 vs 不加），用测试集 AUC/RankIC/分桶单调性判断；成本低、能形成排除法证据；不要默认指标本身有效。
5. 红线：指标必须严格因果（只用 T 及之前，rolling 窗口要 shift），防前视；指标多要防过拟合与多重检验。
