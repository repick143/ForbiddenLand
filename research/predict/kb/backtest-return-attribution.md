# 回测收益归因：beta 漂移 vs alpha

- 标签：`回测` `收益归因` `beta` `alpha`
- 收录日期：2026-10-19

## 最精炼要点

1. "行情漂移"（非标准术语，指 beta/标的自身趋势）：测试窗口内股票池整体上涨，任何"持有"策略都能赚钱；收益来自市场/标的本身的上涨倾向，不是模型预测能力。
2. 判断方法：回测收益 vs 同窗等权 Buy & Hold。若回测收益 ≈ B&H，则无 alpha（模型信号没加分）；只有显著跑赢 B&H 且扣成本后仍为正，才说明信号有用。
3. 本次基线运行（2026-10-19）：回测 +45.7%，同窗等权 B&H ≈ +48% → 收益几乎全部是 beta 漂移；模型信号（AUC≈0.476）反而略拖累。
4. 简化归因：收益 ≈ alpha + beta + 成本损耗；评估模型只看扣成本后的 alpha。
